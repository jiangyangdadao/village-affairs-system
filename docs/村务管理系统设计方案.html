村务数据 · 局域网 · 不上云

村务管理系统设计方案

版本 v1.0（已确认）　日期 2026-09-07　形态 单村局域网版 · 村电脑部署 · 手机浏览器访问

1台村内电脑
1个 exe 双击即用
10张数据表
0云端依赖

01项目概述

为一个村建设一套轻量村务数据系统：村干部在村办公室电脑上维护台账，村民和管理人员用手机浏览器随时查看，数据全部保存在村内电脑，不上传任何云端服务器。

核心价值

  • 一次录入、处处复用：户、人只录一次身份证，十一类台账（含居民信息名册）自动关联，户情报告自动聚合生成，杜绝重复填报。
  • 手机随时查看：村民扫蓝码输身份证查本户信息；村干部扫红码管理全村数据。
  • 零门槛部署维护：一键安装、双击启动、复制文件夹即备份，村干部无需技术背景。

已确认的需求决策

决策点结论
组织范围单村（数据模型预留多村扩展位，本版不实现）
部署位置村内一台 Windows 10/11 电脑，长期开机
访问方式仅局域网（手机连村 WiFi 用浏览器访问），不做远程访问
云端不上传云端服务器；运行期零外网依赖（前端资源本地打包，不用 CDN）
村民查看免登录浏览公开信息；输入本人身份证号查看本人所在户全部信息
管理操作增删改 / 导入导出需输入管理密码（单一密码，无账号体系）
户情报告系统从台账自动聚合生成，可导出 PDF
后台技术Python FastAPI + SQLite
部署方式一键安装 exe + 向日葵远程协助
访问入口双二维码：蓝码 · 村民入口 红码 · 管理入口，安装时自动生成海报打印贴墙

明确不做（边界）

  • 不做微信小程序（强制要求备案域名 + HTTPS 云服务器，与"不上云"冲突）
  • 不做多村/乡镇/县级平台；不做线上办事申请、不接政务接口
  • 不做流程审批、消息推送、通知中心；不使用 WPS 等第三方在线表格
  • 不做 MySQL / Docker / 集群等重部署形态

村民身份证查询规则

  1. 村民在蓝码首页点"我的家庭"，输入本人身份证号（无需注册、无需密码）。
  2. 系统按身份证反查人员表 → 定位其所在户 → 展示该户完整信息（成员构成、政策享受、医保养老缴费、务工等）。
  3. 身份证不在台账中：提示"未查询到您的信息，请联系村干部登记"。
  4. 每次查询记录一条查询日志（时间、来源 IP、查询到的户、结果），村干部可在管理端审计。
  5. 隐私权衡说明：知道他人身份证号即可查看该户信息，这是"输身份证直查"方案的固有特性，已由需求方确认接受。系统不展示所查户以外的任何他人数据。

管理密码

单一管理员密码（PBKDF2 哈希存储），登录后浏览器会话保持（Cookie，7 天或关闭即失效）；所有写操作在管理会话内进行并写入操作日志；密码可随时在系统管理中修改。

05功能模块

6 大模块，全部在一个网页内。台账共用一套通用引擎，交互刻意保持朴素：手机端以查看为主，录入编辑在电脑上进行。管理首页为九宫格：11 个数据台账入口（宫格带实时统计数）+ 6 个功能入口（户情报告、乡村项目、导入 Excel、操作日志、数据备份、系统设置），手机 3 列、电脑 6 列，红=户级台账、蓝=人员台账、灰=功能入口。

模块说明
1. 首页
村民入口		 村情简介（富文本+图片）、公开的项目资料、"我的家庭"身份证查询入口、访问二维码展示（自动读取本机 IP 生成）。
2. 台账中心
管理入口		 11 类台账（居民信息名册 + 十类标签台账），每类：列表（搜索/筛选/排序/分页）、详情、新增/编辑/删除、Excel 模板下载 / 批量导入 / 导出、附件上传（PDF、图片，每文件 20MB 内，图片自动压缩缩略图）。
3. 户情报告
管理入口		 选一户 → 自动聚合：户基本信息、家庭成员表、政策享受清单（含金额）、务工情况、医保养老缴费（近 5 年）、政策性收入合计 → 网页预览 → 导出 PDF（A4，reportlab 生成）。
4. 乡村项目资料 项目列表（名称、类别、投资金额、进度、是否公开）、详情、附件；标记"公开"的项目出现在村民免登录首页。
5. 操作日志与导入记录 操作日志按时间/动作/模块筛选，详情展开变更前后 JSON；村民查询日志（时间、IP、查询到的户、结果，可开关）；导入记录含逐行错误明细。
6. 系统管理 修改管理密码、立即备份/从备份恢复、系统设置（村名、查询日志开关、附件大小限制）、统计看板（各类户数人数、党员数、退役军人数、医保养老参保人数）。

07Excel 模板与导入导出

模板按"村里人看得懂"设计：下拉点选、示例行、逐行错误报告，导入后手机立即可见。

模板规范（每类台账一个模板文件）

  • 单 Sheet 宽表，与村干部现有 Excel 台账样式一致：一户多行（每成员一行，户主信息列逐行重复），导入时按户主身份证自动归并。
  • 表头固定；第二行为灰色示例数据，导入时自动跳过。
  • 性别、与户主关系、监测类别、残疾等级、参保状态等列设置 Excel 数据验证下拉，点选式填写，不手敲。
  • 必填列标 *；日期列统一格式 YYYY-MM-DD；身份证列自动检查位数，默认文本格式避免科学计数法。

导入校验规则（预校验，有错不入库）

  1. 身份证格式：18 位（17 位数字 + 数字/X），15 位老号码警告不阻断。
  2. 必填项缺失：报行号 + 缺失列名。
  3. 同一文件内身份证重复：报重复行号，取最后一行。
  4. 出生日期未填时按身份证第 7-14 位自动补全。
  5. 下拉列取值不在字典内：报行号 + 非法值。

导入策略

  • 匹配键：人员按身份证、户按户主身份证。已存在 → 更新（覆盖同名字段）；不存在 → 新增。
  • 提供"仅新增，不覆盖已有"勾选项（默认覆盖）。
  • 结果摘要：总行数、新增户/人、更新条数、失败条数 + 错误明细表（可导出错误 Excel）。
  • 导入整体记入 IMPORT_LOG 与 OPERATION_LOG。

导出

按当前列表筛选条件导出，列与台账模板一致，可直接当模板复用（首行表头，无示例行）。

09部署与运维

村干部拿到的就是一个文件：村务系统-一键安装.exe。双击后全自动完成部署。

一键安装内容

村务系统-一键安装.exe 双击后自动执行：
  1. 解压程序到 D:\村务系统\（村务系统.exe + web/ 前端 + data/ 数据目录 + 备份.bat + 使用说明.txt）
  2. 创建桌面快捷方式"村务系统"
  3. 设置开机自启（启动文件夹）
  4. 防火墙放行 8080 端口
  5. 检测本机 IP，生成《使用海报.pdf》并自动打开：
     村名 + 蓝码（村民入口）+ 红码（管理入口）+ 三句话使用说明
  6. 完成。村干部打印海报贴墙即部署结束

远程部署协助（开发者视角）

  1. 村干部在村电脑安装向日葵，把识别码 + 验证码发给开发者。
  2. 开发者远程：上传并运行一键安装 → 浏览器验证 →（可选）路由器绑定固定 IP（1 分钟）→ 手机扫码验证 → 告知村干部管理密码。

固定 IP 方案

  • 首选：路由器管理页做 IP-MAC 静态绑定（如 192.168.1.88），一次配置永久有效，海报二维码永不失效。
  • 兜底：IP 变化后管理首页二维码自动更新，重打海报即可。
  • 放弃主机名方案：安卓手机不支持 .local 名称解析，不可靠。

硬件要求

任意 Windows 10/11 电脑（4GB 内存以上），村里现有办公电脑即可；需长期开机、连接村 WiFi/路由器；电脑能上网（收微信安装包），系统运行本身不依赖外网。

10安全与隐私

  1. 数据不出村：全部数据存于村电脑本地，运行期零外网请求。
  2. 管理密码：PBKDF2 哈希存储；建议 8 位以上含字母数字；登录会话 Cookie。
  3. 操作审计：所有写操作与村民查询记录日志（含变更前后 JSON、来源 IP），日志不提供删除功能。
  4. 局域网 HTTP 明文说明：无 HTTPS（局域网无法备案证书），数据在村 WiFi 内明文传输；建议村 WiFi 使用 WPA2 密码且定期更换，管理密码不与 WiFi 密码相同。
  5. 身份证数据：仅存村电脑，本版不做字段级加密（依赖 Windows 账户与实体安全）；如后期有等保要求可再加。
  6. 删除保护：删除前数据完整写入日志可手工恢复；每日自动备份兜底。

12开发实施要点（供编写实施计划参考）

  1. 通用台账引擎先行：字段配置 → 表单/列表/详情自动渲染 → CRUD → 附件 → 日志，跑通低保户一个台账作为样板。
  2. Excel 导入导出是质量关键：模板生成、预校验、错误报告、身份证归并需重点测试。
  3. 村民身份证查询与权限隔离必须用测试覆盖（只能看本户，绝不能越权看到他人）。
  4. 一键安装脚本在纯净 Windows 虚拟机中反复演练（无 Python 环境、不同 IP 段、中文路径）。
  5. 备份恢复演练：模拟数据目录损坏后从备份恢复全流程。
